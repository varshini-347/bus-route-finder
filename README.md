Bus Route Finder is a full-stack web application designed to help users easily find the complete route and list of bus stops for Hyderabad city buses by simply entering a bus number.
The application aims to make public transportation more convenient by providing accurate and organized route information, allowing users to quickly identify the stops served by a particular bus. 
It retrieves bus route data from the GTFS (General Transit Feed Specification) dataset stored in MongoDB and presents the information through a clean, responsive, and user-friendly interface. 
The project is built using React for the frontend, Node.js and Express.js for the backend, and MongoDB for data storage, creating a fast and efficient bus route search experience.
